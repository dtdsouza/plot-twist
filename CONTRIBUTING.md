# Contributing

Thanks for your interest in plot-twist.

> **Heads up:** plot-twist is a personal educational project, not a community-driven product. Pull requests may be reviewed slowly, declined, or left open indefinitely depending on whether they fit the direction I want the codebase to take as a learning exercise. If you want to extend or change the project significantly, forking is usually the better path.

## Getting started

See [README.md](README.md) for prerequisites, install steps, and how to run the API and web apps.

## Conventions

Code style, branch naming, commit format, testing requirements, and the module/schema isolation rules live in [CLAUDE.md](CLAUDE.md). Please read that before opening a pull request.

## Reporting bugs and requesting features

Use [GitHub Issues](https://github.com/dtdsouza/plot-twist/issues). For security issues, follow [SECURITY.md](SECURITY.md) instead — do not open a public issue.
