# Security Policy

Plot-Twist is a personal educational project, not production software. It carries no support or SLA commitments. That said, if you find something that should be disclosed privately rather than as a public issue, the path below works.

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Instead, use GitHub's [Private Vulnerability Reporting](https://github.com/dtdsouza/plot-twist/security/advisories/new) to file a confidential report. I'll respond on a best-effort basis.
